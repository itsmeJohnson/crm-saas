# Johnson CRM Constitution

## Core Principles

1. Never break multi-tenancy.

2. Never hardcode any industry-specific logic.

3. Every organization should be able to configure its own workspace.

4. Never implement a feature without auditing the existing implementation.

5. Never redesign architecture without approval.

6. Production-ready code only.

7. No mock data unless explicitly requested.

8. Security before convenience.

9. Performance is a feature.

10. Every feature must be documented.

11. Every feature must be tested.

12. Keep the code simple, maintainable and scalable.

13. Backward compatibility should always be preserved.

14. Every commit should improve the product.
